# Music Mood Recommender

Итоговый ML-проект: веб-приложение для определения настроения песни и музыкальных рекомендаций.

## Возможности

* ML-классификатор настроения песни;
* рекомендации треков на основе настроения;
* поиск похожих песен;
* поиск похожих исполнителей;
* генератор плейлистов;
* EDA, предобработка, кросс-валидация и подбор гиперпараметров.

## Запуск

```bash
pip install -r requirements.txt
python train_model.py
python app.py
```

Откройте http://127.0.0.1:5000

Проект использует файл `dataset.csv` из этой папки.

## Расширенный EDA-ноутбук

Откройте `EDA_Music_Mood_Recommender.ipynb` в Jupyter Notebook или VS Code, чтобы посмотреть дополнительную статистику датасета, распределения жанров, гистограммы признаков, корреляции, карты настроения и анализ на уровне исполнителей.

## Рекомендация плейлистов

Playlist Generator реализован как content-based recommender. Для каждого режима прослушивания задан целевой аудиопрофиль, а треки ранжируются по косинусному сходству с этим профилем после применения пользовательских фильтров.

## Классификатор с учётом утечки данных

Целевое настроение создаётся на основе `energy`, `valence`, `danceability` и `acousticness`, потому что в датасете нет исходной метки настроения. Эти четыре признака, использованные при создании целевой переменной, исключаются из входных данных классификатора, поэтому модель предсказывает настроение по косвенным признакам, таким как `tempo`, `loudness`, `speechiness`, `instrumentalness`, `popularity`, `genre` и `explicit`. Рекомендательные модули при этом используют полный аудиовектор, что корректно для content-based retrieval.
